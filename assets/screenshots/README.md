# Screenshot drop folder

Place final gameplay PNGs here. Suggested names:

- `01-storage-toggle.png`
- `02-botanist-storage.png`
- `03-chemist-workflow.png`
- `04-handler-workflow.png`

Use 1920x1080 or native resolution and avoid overlays from other mods where possible.

Short GIFs go in `assets/gifs/` and should stay below 10 MB when possible.
