# The Employees Know

**Your workforce finally knows where everything is.**

The Employees Know makes employees use the storage you have already built. Botanists, chemists, handlers and other workers can take what they need from enabled storages on their property instead of relying only on the vanilla supply locker.

## Features

- Employees can use enabled storages on their property.
- Botanists can fetch soil, seeds, additives and spawn, and can use drying racks and spawn stations from storage.
- Chemists can fetch ingredients for chemistry stations, mixers, cauldrons and lab ovens.
- Handlers can fetch inputs for packaging stations and brick presses.
- Employees can use parked delivery vans as temporary storage.
- Per-storage employee access toggle in the storage menu.
- No artificial 10-item trip limit; movement is limited by the game's real slot and stack capacity.
- Fully configurable and host-side.

## Requirements

- Schedule I (tested on 0.4.7f12).
- MelonLoader 0.7.3 or newer.
- IL2CPP branch only. This build does not support the Mono/Alternate branch.
- No S1API dependency required.

## Installation

1. Install MelonLoader for Schedule I.
2. Extract `SmartStorage.dll` from the release ZIP and place it in the game's `Mods` folder.
3. Launch the game.
